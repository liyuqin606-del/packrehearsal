# Support

PackRehearsal is community-supported open-source software.

- Use [GitHub Discussions](https://github.com/liyuqin606-del/packrehearsal/discussions)
  for installation and usage questions.
- Use the structured [issue forms](https://github.com/liyuqin606-del/packrehearsal/issues/new/choose)
  for reproducible bugs and evidence-backed rule proposals.
- Use [private vulnerability reporting](https://github.com/liyuqin606-del/packrehearsal/security/advisories/new)
  for security-sensitive reports.

Please include the PackRehearsal version, operating system, ecosystem, command,
and a minimal public reproducer. Support has no guaranteed response time except
for the security-response targets in `SECURITY.md`.
